# AI 技术发展历程 · 交互时间线

纯静态、零依赖的单页网站：横向时间轴展示人工智能 1950 至今的重大事件，理论性节点内置**可交互的原理演示**。

- **在线预览**：<https://real-injw.upma.site/>
- **GitHub**：<https://github.com/Chatbot-zhou/The-Development-History-of-Artificial-Intelligence>
- **Gitee**：<https://gitee.com/chatbotzhou/the-development-history-of-artificial-intelligence>

> 每完成一个版本，代码会同步推送到 GitHub 与 Gitee 两个仓库，静态站点随仓库更新自动部署。

## 打开方式

直接**双击 `index.html`** 即可在浏览器中打开（无需服务器、无需安装任何东西）。

也可以部署到任意静态托管（GitHub Pages / 服务器目录等），拷贝整个文件夹即可。

## 使用方法

1. **横向模式（默认）**：首页是横向时间轴，按**真实时间比例**排布，相邻年份过近时节点自动一上一下交错展示，年份数字淡灰色低调。**同一年有多件大事时合并为一个年份节点**（右上角橙色上标显示数量）。**滚轮**左右移动浏览全部事件，**Ctrl+滚轮**缩放，**按住拖动**平移，右下角有缩放/复位按钮；悬停节点显示标题摘要。
2. **点击年份节点** → 动画转场进入**竖向模式**：时间轴移到页面左侧竖向排布，未选中的年份收起为淡淡的圆点，只有当前年份展开；右侧详情面板中，这一年的多件大事以**堆叠卡片**逐件呈现。
3. 竖向模式下**滚轮**在卡片之间上下滑动，滑到末尾继续滚则自动切换到下一年份（向上同理）；**↑↓ 方向键**直接切换年份，左侧列表随之"转动"，当前项始终居中；点击轨道上的圆点可跳转任意年份。
4. 面板左上角只有一个**返回按钮**：演示页返回介绍页，介绍页返回时间轴（Esc 同效）；每件大事若有 **互动演示** 按钮可进入动态演示。卡片为统一固定尺寸，年份与标题位于卡片左上角。

## 十二个互动演示

| 节点 | 演示内容 |
|---|---|
| 1957 感知机 | 点击画布放样本，实时训练线性模型/神经网络，观察决策边界收敛与 loss 曲线 |
| 1986 反向传播 | 损失地形上放小球下山，学习率滑块演示"步子太大爆炸、太小收敛慢" |
| 1995 特征工程 | 双臂螺旋数据：原始特征分不开 → 加 x²+y² 特征立刻分开 |
| 1998 LeNet-5 | 2-4-4-2 网络前向传播动画，信号光点逐层流动，点击神经元看激活值 |

| 2017 Transformer | 点击任意 token，动画展示 Q/K/V 分裂 → 注意力连线（粗细=权重）→ 加权求和；附注意力热力图 |
| 1966 ELIZA | 与真实还原的 ELIZA 对话，可透视每条回复背后的关键词匹配规则 |
| 2012 AlexNet | 手绘图案 → 选择 3×3 卷积核 → 逐行扫描计算特征图 → 最大池化（真实卷积） |
| 2014 GAN | 一维世界里的真实生成对抗训练：生成器追逐双峰分布，观察模式崩塌 |

| 2022 扩散模型 | 像素级真实的加噪/去噪动画：会去噪 = 会生成 |

所有"训练/注意力/估值"均为**前端真实数值计算**（逻辑回归、BP 神经网络、softmax 注意力、Q-learning），非预录动画。

## 目录结构

```
index.html          入口
css/                样式（米白主题 + 亮蓝/暖橙/亮绿点缀）
js/data.js          时间线事件数据（增删事件改这里）
js/timeline.js      时间轴渲染与拖拽/缩放
js/detail.js        事件详情弹层与演示挂载
js/demos/           六个演示模块（互相独立，经 DemoRegistry 注册）
assets/img/         历史事件图片（来自维基共享资源等公开渠道）
```

## 如何新增时间线事件

在 `js/data.js` 的 `TIMELINE_EVENTS` 数组里追加一项：

```js
{
  id: "唯一id", year: 2025,
  title: "标题", tagline: "一句话副标题",
  type: "milestone",            // milestone | theory | era
  img: "assets/img/xxx.jpg",    // 可选
  desc: ["段落一", "段落二"],
  theory: { title: "…", text: "…" },  // 可选，理论说明框
  demo: "attention"             // 可选，关联演示模块 id
}
```
